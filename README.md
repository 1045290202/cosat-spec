# Cosat 语言规范

**版本**：Cosat v0.1 ｜ **状态**：设计定案 ｜ **修订日期**：2026-08-24

## 语言简介

Cosat 是一门**数据流范式**的脚本语言（源文件扩展名 `.cst`）：代码即数据从左向右的流动，语法的一切设计服务于"看清数据去了哪里"。

语言名 Cosat 取自 **Co**urier（信使）与 **S**t**at**ion（车站），意为"快递站"——数据如同包裹，沿链从左向右逐站投递，这正是全语言的核心隐喻。

```cosat
# 定义 = 构造 + 流入 def；分支体泛化：常量分支免 lambda 包装
\ n => match n {
    0 : 0
    1 : 1
    _ : (n - 1 -> @fib) + (n - 2 -> @fib)
} -> def fib;

10 -> @fib -> @print;                # → 55

# 链上定义（tee）：d 绑定后原值继续流
data -> def d -> match _ {…}, d -> @log;

# 循环：表达式体收集（map）、遍历带守卫（filter）
each nums { _ * 2 } -> def doubled;
each nums { _ > 0 : @print }
```

## 核心设计公理

1. **数据流高于一切**——数据从左向右流动；
2. **目的地殿后**——值在前，目的地在后：`实参 -> 函数`、`值 -> def 名字`；
3. **符号单一含义**——每个符号只有一个语义、一个方向，不兼职；
4. **角色不明则前缀声明**——形参 `\`、调用 `@`、占位 `_`；
5. **歧义必须在文法层消灭**——用结构区分语义，不依赖位置或语境；
6. **接收点显式**——链路中接收者必须自带显式、裸露、唯一的接收点。

完整公理与细节见 [spec/00-总览-OVERVIEW.md](./spec/00-总览-OVERVIEW.md)。
