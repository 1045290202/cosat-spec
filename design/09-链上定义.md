# 链上定义：`-> def` 与 `>>` 退役（2026-08-22 定案）

对应全部规范文档的状态变更记录。本页为决策原文，规范正文已同步。

## 背景与框架

`->` 的含义始终是**传递**；**存储是 `def` 表达式内置的功能**。def 与 `@fn` 对称：`@fn` 内置调用、`def` 内置绑定，各自暴露恰好 1 个接收点，`->` 语义零特例。存储不再是独立运算符，`>>` 退役回未占用符号池。

## 定案清单

| # | 决策 | 内容 |
| --- | --- | --- |
| 1 | def 三通（tee） | `data -> def d -> @next` 成立：d 绑定后**原值透传**给后续段 |
| 2 | 作用域 = 所在作用域 | 链中 / 链尾 def 一律绑定在**所在作用域**（程序 / 块 / lambda 体）；可见性从绑定点起（链前段与先前代码不可见，链后与后续段可见）。不做"链尾 vs 链中"的位置区分（语境依赖语义，违反公理 5） |
| 3 | 无变异、遮蔽式 | `i + 1 -> def i` 不是重绑定，是**新的局部变量**（遮蔽外层同名）。语言无赋值语义 |
| 4 | 点位固定 1 | `a, b -> def pair` 编译错（2 值 ≠ 1 位）；`a, b -> def p1, def p2` 合法（各取 1）。多返回值只能解构命名，不可整体命名 |
| 5 | 泛化站点 0 位规则 | 站点位的普通表达式一律 **0 接收点**（`data -> (_ + 1)` 断流编译错）；只有裸 `_` 才是 1 位；带洞计算用 lambda：`data -> @(\ _ => _ + 1)`。括号不改变裸露性（`(_)` 视同 `_`） |
| 6 | 体边界统一（甲） | `->` 优先级高于函数声明：**一切位置**的单行体都到第一个未配对 `->` 或 `;` 止。"语句位体可含管道"特例删除；管道入体用块体 `\ x => { x -> @double -> @inc }` |
| 7 | `>>` 退役 | 从运算符表与符号分工表移除，记入 [docs/10-废案](../docs/10-废案-REJECTED.md)，回未占用符号池 |

## 连锁后果

### 条件型循环失去内部状态机制

无变异语义下，`~ { cond : \ => { sum + i -> def sum; … } }` 的块内 def 是每轮新建的局部，循环间不延续——while 式状态机不可写。替代路径：

1. **递归**（fib 同款）表达迭代与状态机；
2. 远期引入**显式可变容器**（类型系统期评估）。

守卫由外部世界驱动变化的轮询场景（每次守卫求值经 `@` 调用读到新外部状态）不受影响。

### 多返回值命名受限

`@\ a, b => b, a -> def s` = 2 值 ≠ 1 位，编译错；只能 `-> def s1, def s2` 解构。远期可评估**括号分组字面量** `(e1, e2)` 作头值恢复整组命名（语法位空闲）。

### 顺带解决的旧开放问题

- 链式 `def` 待定（速查 `1 >> def x >> y;`）：定案为合法 tee 链 `1 -> def x -> def y;`；
- 重绑定定案：判死变异方向，条件型循环依赖解除方式如上。

## 迁移对照

| 旧（`>>` 时代） | 新 |
| --- | --- |
| `1 >> def x;` | `1 -> def x;` |
| `\ x => x * 2 >> def double;` | `\ x => x * 2 -> def double;` |
| `\ x => x -> @double -> @inc;`（语句位体内管道） | `\ x => { x -> @double -> @inc }` |
| `data >> def d; d -> ? _ {…}, d -> @fn;` | `data -> def d -> ? _ {…}, d -> @fn;` |
| `? x { … } >> def r;` | `? x { … } -> def r;` |
| `0 >> def i; 0 >> def sum;` | `0 -> def i; 0 -> def sum;` |
