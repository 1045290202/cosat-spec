# 运算符设计决策

对应 [docs/03-运算符](../docs/03-运算符-OPERATORS.md)。

## 比较高于加减（反主流）

`<` `>` 优先级最高（高于 `* /` 与 `+ -`）是刻意的链式比较取向：`a < b < c` 无需括号。代价是 `1 < 2 + 3` 的 AST 为 `(1 < 2) + 3`，与主流直觉相反——已登记为已知问题，修复方向是输出层按优先级补括号（见 docs/11）。

## 结构性前缀不入优先级表

`\` `?` `~`（及 `=>`）是**结构开启符**而非表达式运算符：它们开启的是块 / 分支列表 / 函数定义，其作用域由扫描边界规则界定（体终止符表、守卫扫描到 `:`、被匹配值 / 源扫描到 `{`），与二元优先级比较是两个机制，混入优先级表只会产生假规则。

## 函数声明优先级最低

`>>` 与 `->` 的优先级高于函数声明（单行体扫描到第一个未配对的 `>>` / `->` / `;` 截止），动机：

1. **定义 = 构造 + 存储** 是最高频写法，`\ x => x * 2 >> def double` 无需括号；
2. **裸链中内联重排** `data1, data2 -> @\ a, b => b, a -> @fn` 无需括号；
3. lambda 体要含管道时用括号显式表态（`data -> @(\ x => x -> @f)`），结构边界与语义边界重合。
