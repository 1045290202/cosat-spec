# 运算符设计决策

对应 [docs/03-运算符](../docs/03-运算符-OPERATORS.md)。

## 主流优先级（2026-08-22 定案）

二元层级定为 `* /` ＞ `+ -` ＞ `< >` ＞ `==`（用户定向：加法优先级须高于比较）。此前「比较高于加减」的链式比较取向被否决：其代价是 `1 < 2 + 3` 的 AST 为 `(1 < 2) + 3`，内部层级与主流直觉相反，导致输出必须补括号才能被安全复读（原已知问题）；重排后内部层级 = 常规解析层级，AST 原样输出即正确，「输出层按优先级补括号」方案随之作废。链式比较本就被单可选文法禁写（`comparison = additive , [ op , additive ]` 只允许一次比较），重排不损失表达力。

注：结构性前缀 `\` 及关键词构造 `when` `match` `each` `while` 不入优先级表（原 `\ ? ~` 符号家族，2026-08-22 拆分为关键词，见 [design/06](./06-匹配.md)、[design/07](./07-循环.md)）。

## 函数声明优先级低于 `->`

`->` 的优先级高于函数声明，且一切位置统一：单行体扫描到所在文法位的第一个未配对封闭符（语句位 / 站点位为 `->` 或 `;`）截止。动机：

1. **定义 = 构造 + 流入 def** 是最高频写法，`\ x => x * 2 -> def double` 无需括号；
2. **裸链中内联重排** `data1, data2 -> @\ a, b => b, a -> @fn` 无需括号；
3. lambda 体要含管道时用块体或括号显式表态（`data -> @(\ x => x -> @f)`），结构边界与语义边界重合——存储也走 `->`（2026-08-22 定案，[design/09](./09-链上定义.md)）后，若保留「语句位体可含管道」特例，「定义函数」与「体内 tee 绑定」将无法区分，故统一截断规则并删除该特例。
