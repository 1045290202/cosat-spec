## 文法

形式文法见 [12-文法 §12.3](./12-文法-GRAMMAR.md)。

存储不是运算符：定义走链站点 `-> def 名字`（[04-链模型](./04-链模型-CHAIN.md)、[design/09](../design/09-链上定义.md)）。结构性前缀 `\` 与 `=>` 不入优先级表；关键词构造 `when` `match` `each` `while` 同为结构开启符，亦不入优先级表——它们的作用域由扫描边界规则界定（见下）。

## 规则

| 优先级 | 运算符 | 备注 |
| --- | --- | --- |
| 4（最高二元） | `*` `/` | |
| 3 | `+` `-` | |
| 2 | `<` `>` | 主流层级（2026-08-22 定案：加减高于比较） |
| 1 | `==` | 严格相等 |
| 待定 ⏳ | `? :`（中缀三元；若定案则最低、右结合） | 见 [06-匹配 §7.2](./06-匹配-MATCH.md)；`?` 前缀职责已退役，中缀启用无冲突 |
| 单目 | `+` `-` `!`（前缀） | 高于一切二元；嵌套单目输出时加括号 |
| 前缀 | `@` | 与单目同级，高于一切二元 |

## 函数声明优先级低于 `->`（🔒 定案）

`->` 的优先级高于函数声明，且**一切位置统一**：单行 lambda 体自 `=>` 后开始扫描，遇到第一个**未配对**的 `->` 或 `;` 终止；配对块 / 括号内的同名符号不截断（扫描跳过配对单位）。动机见 [design/03](../design/03-运算符.md)、[design/09](../design/09-链上定义.md)。

```cosat
\ x => x * 2 -> def double;              # 体到 -> 止：体 = x * 2，函数流入 def 存储
data1, data2 -> @\ a, b => b, a -> @fn;  # 站点位同理：体 = b, a，其后是新的链段
\ x => x -> @double -> @inc;             # ✕ 单行体到第一个 -> 止：体 = x，
                                         #    语义变为「恒等函数流入 @double」——管道入体必须块体：
\ x => { x -> @double -> @inc }          # ✓ 块体内管道自由，不受截断
```

分支体位扫描到 `;`（语句位单行体分隔）/ `}`，循环体位扫描到 `}`，守卫扫描到 `:`，括号内到 `)`（见 [05-函数 §6.1](./05-函数-FUNCTIONS.md)、[06-匹配](./06-匹配-MATCH.md)）；块体以配对的 `}` 闭合，不受截断影响。

## 已知问题

无。原「优先级与输出不协同导致语义反转」（`1 < 2 + 3` 的 AST 为 `(1 < 2) + 3`，原样输出会被按常规优先级复读为 `1 < (2 + 3)`）已于 2026-08-22 由优先级重排根治——内部层级与主流一致后，AST 原样输出即可被正确复读；取代记录见 [10-废案](./10-废案-REJECTED.md)。
