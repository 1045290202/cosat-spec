## §3 符号分工表

| 符号 | 唯一含义 | 方向 / 示例 |
| --- | --- | --- |
| `->` | **传递**：把左边的东西送到右边的接收者。仅用于链段（定义箭头由 `=>` 专职）；调用、绑定是接收者的内置功能 | `data -> @f`、`1 -> def x` |
| `=>` | **函数构造**：形参 → 体（函数定义专用箭头） | `\ x => x * 2` |
| `\` | **构造前缀**：开启函数定义（形参 + 体 → 函数值） | `\ x => x * 2` |
| `@` | **调用**：裸标识符永远是引用，`@` 标记该标识符是一个调用 | `@f`、`data -> @f` |
| `_` | **占位**：上游数据落点（合并段 / match arg 位 / 循环源位）/ match 默认守卫 / 守卫表达式内被匹配值引用 / 泛化体内被匹配值、循环元素的引用型绑定 | `data -> @f, _ -> @g` |
| `def` | **定义站点**：内置绑定——上游数据绑定到名字，原值透传；恰好 1 个接收点 | `1 -> def x`、`a, b -> def p1, def p2` |
| `match` | **值分发**：对单一被匹配值按分支列表多路分发 | `match x { 1 : A  _ : B }` |
| `when` | **条件分发**：多守卫布尔表达式列表，自上而下短路 | `when { x < 0 : A  _ : B }` |
| `each` | **遍历**：源逐元素流入体；带守卫形态 = 遍历 + 过滤；站点位源仅限 `_` | `each xs { _ * 2 }`、`data -> each _ { 体 }` |
| `while` | **条件循环**：守卫每轮重评、命中执行回顶部、全假退出 | `while { @running : 体 }` |
| `.` | 成员访问（上一 token 为标识符时；否则小数点） | `@obj.method` |
| `==` | 相等（严格相等——总函数：类型不同直接 false；判定表见 [09-数据类型 §9.7](./09-数据类型-TYPES.md)） | `a == b` |
| `#` / `#$ $#` | 注释 | — |
| `;` | **流动分隔（语义分号）**：数据未到终点，值在此丢弃、流继续；块尾无分号 = 值的出口 | `x -> @log;` vs `{ x * 2 }` |
| `:` | **分支分隔**：分支左侧（判定）与分支体（接收者）之间；守卫扫描到 `:` 为止 | `_ > 0 : \ x => …` |

> **token 内部构成注记**：字母与下划线可作标识符成分、`_` 可作数字字面量分隔符（[09-数据类型 §9.2](./09-数据类型-TYPES.md)）——此类出场是字符参与 token 拼写，不构成符号兼职。

## 符号禁区（未来特性选号约束）🔒

- 模块/命名空间路径**不得用 `\`**（词法冲突），锁定 `.` 或 `::`；
- 装饰器/注解**不得用 `@`**（已占用为调用标记），`#` 亦不可（注释）；
- **`=` 已被 `=>` 前导消费**：不存在独立 `=` 赋值语义，存储恒走链站点 `-> def`；未来 `=` 系组合符（`==` 除外）须避开 `=>` 贪婪匹配；
- 未占用符号池：`::` `|` `&` `%` `^` `'` `[` `]` `>>` 等（`(` `)` 已占用为括号分组 / 动态站点 / 嵌套前缀结构消歧，不入池），新特性启用前先查本表（`,` 已占用为参数组分隔）；`:` 已被分支分隔占用——类型标注启用时**错位共存**（类型在形参后、`=>` 前：`\ x: T => …`），启用时需复核；`|` `&` `^` `%` 为未来逻辑/位/模二元运算的仅存候选，原则上不作前缀消费。`>>` `?` `~` 也在未占用池内（`?` 保留给待定三元 `c ? a : b` 的候选形态）。
