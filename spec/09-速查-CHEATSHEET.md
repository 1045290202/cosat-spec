## §9 判定规则速查表

### 链与调用

| 写法 | 判定 | 语义 |
| --- | --- | --- |
| `data -> @f` | ✓ | `f(data)` |
| `a, b -> @f` | ✓ | `f(a, b)` |
| `data -> f` | ✕ | 站点位缺少 `@`（显式调用） |
| `@f;` | ✓ | `f()` |
| `@f -> @g` | ✓ | `g(f())` 源头值位 |
| `@@f;` | ✓ | `f()()` 右结合，内层先执行 |
| `data -> @h, _ -> @g` | ✓ | `g(h(), data)` @ 在参数组 |
| `data, fn -> @g` | ✓ | `g(data, fn)` 裸标识符传引用 |
| `data, @fn -> @g` | ✓ | `g(data, fn())` @ 调用入组 |
| `data -> @f -> 1, _, 2 -> @h` | ✓ | `h(1, f(data), 2)` |
| `data -> @(\ x => x * 2)` | ✓ | 内联立即调用（动态站点） |
| `data1, data2 -> @\ a, b => b, a -> @fn` | ✓ | 参数重排 → `fn(data2, data1)`；体到 `->` 止 |
| `\ x => x * 2 -> def double;` | ✓ | 定义 = 构造 + 流入 def；单行体扫描到 `->` 止 |
| `\ x => x -> @double -> @inc;` | ✕ | 单行体到第一个 `->` 止：体 = `x`；管道入体用块体 `\ x => { … }` |
| `data -> def d -> @next;` | ✓ | def tee：d 绑定后原值流入 @next（[design/09](../design/09-链上定义.md)） |
| `a, b -> def p1, def p2;` | ✓ | 各取 1 个：p1 = a、p2 = b |
| `a, b -> def pair;` | ✕ | 2 值 ≠ 1 点位；多返回值只能解构命名 |
| `i + 1 -> def i;` | ✓ | 新局部变量（遮蔽外层），非重绑定——语言无赋值语义 |
| `data -> (_ + 1);` | ✕ | 泛化表达式 0 接收点，断流编译错；带洞计算用 lambda |
| `data1, data2 -> _, _ -> @f;` | ✓ | 双槽逐位消费 → `f(data1, data2)` |
| `data -> _, _ -> @f;` | ✕ | 1 值 ≠ 2 点位；同值双传用 `def d` 中转 |
| `data -> @fn1, data2 -> @fn2` | ❓ | 按点位模型推导为 `fn2(fn1(data), data2)`，语义待定案（见 [04-链模型 §5.1](./04-链模型-CHAIN.md)） |
| `@1` / `@!f` | ✕ | 操作数不可调用 |

### 站点位

| 写法 | 判定 | 语义 |
| --- | --- | --- |
| `data -> @obj.method` | ✓ | dot 链显式调用 |
| `data -> (@@fn)` | ✓（❓ 语义待对齐） | 动态站点，见 [05-函数 §6.4](./05-函数-FUNCTIONS.md) |
| `data -> { … }` | ✕ | 站点位禁块 |
| `a, b -> { … }` | ✕ | lambda/调用不可区分，用 `\` |
| `data -> @` | ✕ | 站位点禁裸 `@` |
| `data -> (_ + 1)` | ✕ | 普通表达式 0 接收点；只有裸 `_` 是落点 |

### match 与 when

| 写法 | 判定 | 语义 |
| --- | --- | --- |
| `when { c : \ => { A; }; _ : \ => { B; }; };` | ✓ | when 条件分发语句位（单行体 `;` 分隔） |
| `match x { 1 : "A" _ > 99 : _ _ : "C" } -> def r;` | ✓ | match 值位：泛化体（常量 / `_` 直通 / default），穷尽 |
| `match x { _ > 0 : x + 1 _ : 0 } -> def r;` | ✓ | 0 位体按名引用被匹配值 |
| `match x { _ > 0 : @incr };` | ✓ | 函数引用路由，显式调用 |
| `match x { y : \ => { A; } }` | ✕ | 裸标识符分支：比较还是绑定真歧义 |
| `match x { y > 0 : \ => { A; } }` | ✕ | match 守卫必须引用 `_`（纯布尔守卫请用 when） |
| `match x { _ > 0 : @twoArgFn }` | ✕ | 点位不匹配（2 位 ≠ 1 值） |
| `when { _ > 0 : \ => { A; } }` | ✕ | when 无被匹配值，`_` 未定义 |
| `when { … } -> def r;` | ✕ | 值位必须穷尽（无单独 `_` default）；守卫式 `_ > 99` 不构成穷尽保障 |
| `match match x { A } { B }` | ✕ | 嵌套未加括号：内层 `{` 被外层吞并；须写 `match (match x { A }) { B }` |
| `match x + 1 { … }` | ✓ | 裸表达式被匹配值不加括号（扫描到 `{`） |
| `match x < 0` | ✕ | match 必须跟 `{` |

### 循环

| 写法 | 判定 | 语义 |
| --- | --- | --- |
| `each xs { _ * 2 } -> def d;` | ✓ | 泛化表达式体恒收集 |
| `each xs { \ x => x * 2 } -> def d;` | ✓ | lambda 表达式体恒有值（§7.3） |
| `each xs { @log };` | ✓ | 引用体副作用遍历，语句位不收集 |
| `each xs { \ x => { x -> @log; } };` | ✓ | 块体尾分号 → 不收集 |
| `each xs { _ > 0 : @log };` | ✓ | 遍历带守卫：仅命中元素流入体 |
| `data -> each _ { \ x => x * 2 } -> @sum;` | ✓ | 站点位循环：源位 `_` = 上游，元素流入体形参 |
| `while { @running : \ => { … } };` | ✓ | while 条件循环：外部状态驱动退出（内部状态机走递归，[design/09](../design/09-链上定义.md)） |
| `each xs { x * 2 }` | ✕ | x 未绑定，元素未被消费 → `_ * 2` 或 lambda |
| `each xs { @twoArgFn }` | ✕ | 点位不匹配 |
| `each i < 10 { … }` | ✕ | 源是比较式，用 while |
| `each 5 { … }` | ✕ | 数字字面量非源 |
| `while { _ : \ => { A; } }` | ✕ | `_` 守卫 = 无限循环（v1 禁，随 break 解禁） |
| `data -> each xs { }` | ✕ | 站点位循环源必须 `_`，上游断流 |
| `each _ * _ { }` | ✕ | 源层 `_` 仅单独作源；`_ * _` 非合法源形态（[07-循环 §7.3.2](./07-循环-LOOP.md) 白名单） |
| `data -> match _ { … } -> each _ { \ x => … }` | ✓ | match 选出可迭代值、站点循环接续——复杂源需求的链式分解形态（两段各自绑定） |
| `(each xs { \ x => { x -> @log; } }) -> def r;` | ✕ | 值位循环体必须有值出口 |
| `data -> while { 守卫 }` | ✕ | while 不可入链 |
