2. **词法最长匹配 + 回退**；
3. **循环**（设计定稿见 [07-循环](./07-循环-LOOP.md)；实现顺序：Token 空白/span → Block.tail → 接收点位计数 → 解析上下文 → 遍历型 → 遍历带守卫 → while 条件循环（重绑定已定案为无变异遮蔽，[design/09](../design/09-链上定义.md)）；break/continue 与 `_` 守卫解禁随后）；

5. **类型系统**：类型标注（`a: number`——`:` 已被分支分隔占用（[02-符号](./02-符号-SYMBOLS.md) 错位共存约束），类型标注启用时需复核或改 `::`；标注位在形参后、`=>` 前）、动态站点括号简化（编译期可证 `@fn` 返回函数类型时）、自动部分应用、类型驱动补全（解决"写函数名前不知参数"的根本方案）、内置/外部函数 arity 声明（点位模型前置依赖，见 [05-函数 §6.6](./05-函数-FUNCTIONS.md) 开放问题 6）；
6. **模块系统**（路径分隔符锁定 `.` 或 `::`）；LSP；空值合并 `??`（符号已预留）；
7. **前缀操作符协议**：自定义操作符 = 注册 `(符号, 高阶函数)`，声明操作数/块内文法（分支列表或接收者）/数据流入规则；约束：遵守前缀空格规则、禁中缀（判定封闭）、接收点纪律——`\` `@` 为协议内置符号实例，`when` `match` `each` `while` 为内置关键词实例；
8. **优化路线**：分支体 / 循环体字面 lambda **β-内联**（**纯重排 β-归约**已定案，见 [05-函数 §6.5](./05-函数-FUNCTIONS.md)）→ 单赋值 `def` 传播 → 无捕获 lambda 提升 → `each` 链**循环融合**（deforestation 消中间数组）；
9. **字面量与值域扩展** ⏳（2026-08-25 登记）：多行字符串、模板插值、科学计数法、进制前缀（[15-数据类型](./15-数据类型-TYPES.md) §15.2/§15.3）、复合值深度相等方案（§15.7）、字符串字典序比较与完整转义集（§15.3/§15.8）、用户自定义二元重载协议（§15.8——与第 7 位前缀协议互补：那边管前缀新符号注册，这边管既有中缀符号的类型实例扩展，新增中缀符号仍禁）。

## 实现顺序

1. **词法层**：`@` 识别（独立 token）；`=>` 双字符 token（贪婪匹配，见 [01-词法](./01-词法-LEXICAL.md)）；
2. **解析层**：站点位要求 `@` 前缀（裸标识符站点位报错）；参数组内 `@` 标记调用；`=>` 为定义箭头；
3. **语义层**：点位收集 + 数量校验（`@fn` = fn 形参数，`_` = 1，裸引用/字面量 = 0）；`@` 右结合求值（内层先执行）；AST 附 `receive_points` 字段（泛化体共用）；
4. **输出层**：`@fn` → `fn()` / `fn(data)`；`@@fn` → `fn()()` / `fn(data)()`；泛化体直接嵌入（`_` 替换为绑定名）；纯重排归约。
