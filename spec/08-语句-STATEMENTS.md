## 规则

| 结构 | 语法 |
| --- | --- |
| 程序 | 语句序列 |
| 块 | `{ 语句* }` |
| 块值 | 块尾**无分号**语句的值 |

**语义分号（🔒 定案）**：`;` 的含义 = **数据未到终点，需要继续流动，不能在此被拦住**（该值在此处被丢弃，流继续）。

- **双重职责二分**：块中/顶层语句间分号必需（分隔职责）；块尾分号只剩语义作用；
- **块值规则**：块尾最后一条语句**无分号** → 其值为块值（流出）；**带分号** → 值丢弃，块值为空值；
- **嵌套块统一**：任何位置的块语句其块值同样受分号控制——`{ a; { b } }` 外层块值 = b；无特例；
- **函数返回值 = 体块值（隐式返回）**：`\ x => { x * 2 }` 值出口；`\ x => { x -> @log; }` 副作用出口；无 return 概念，提前返回用 match 分支表达；
- **迭代维度延伸**：循环体尾分号 = 收集开关（[07 §7.3.1](./07-循环-LOOP.md)）；分支单行体间分号 = 值丢弃（[06-匹配](./06-匹配-MATCH.md)）；
- 词法注记：块尾值贴 `}` 的写法（`x + 1}`）比贴 `;` 更安全——词法器对 `}` 有显式边界处理；
- 实现注记：AST 需记录块尾语句有无分号（`Block.tail` 字段）；
- **出口纪律（风格规则，类型系统前）**：一个函数的所有出口应流出同类型值；值位 match 各支路应产出值或显式无值（空块）；副作用函数只放语句位或链尾，链中间站点必须是值变换——动机见 [design/08](../design/08-语句.md)；
- **类型系统期收益**（远期）：返回类型标注、多出口同型检查、void 流入下游编译错拦截——见 [design/08](../design/08-语句.md)；
- **nil 字面量** ⏳：可选补充，非必要解；
- 返回值处理的否决记录见 [10-废案](./10-废案-REJECTED.md)。
