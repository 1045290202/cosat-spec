## 语言定位

Cosat 是一门**数据流范式**的语言：代码即数据从左向右的流动，语法的一切设计服务于"看清数据去了哪里"。语言名 Cosat 由 **Co**urier 与 St**at**ion 组合而来；脚本文件扩展名为 `.cst`。

## §1 设计公理

1. **数据流高于一切**：数据从左向右流动；
2. **目的地殿后**：值在前，目的地在后——`实参 -> 函数`、`值 -> def 名字`；
3. **符号单一含义**：每个符号只有一个语义、一个方向，不兼职：`->` 专职传递（调用、绑定是接收者的内置功能），`=>` 专职函数定义，`@` 专职调用标记（见 [02-符号](./02-符号-SYMBOLS.md)）；
4. **角色不明则前缀声明**：形参 `\`、调用 `@`、占位 `_`；
5. **歧义必须在文法层消灭**：两语义角色词法不可区分时用结构区分；仅差单字符且语义不同的写法，弱者非法（防 typo 静默漂移）；
6. **接收点显式**：`->` 右侧 = 接收者，必须自带显式落点声明，每个接收者恰一个；不含落点的裸算式 / 裸 `@` / 块不能作接收者，含 `_` 落点的泛化表达式按接收点位模型计位（见下）；每跳点位总数 = 上游数据量（编译期校验）。链外（链首 / 语句位 / 值位）构造自带头部操作数，不承担接收职责。**接收 ≠ 使用**：约束的是接收动作的落点，数据落定后在接收者内部参与表达式属使用、不受此限——论证见 [design/00](../design/00-公理与接收点.md)。
   > **接收点位模型**：公理 6 泛化为**接收点位匹配**——接收者不必是函数，任何表达式按**接收点位数**参与匹配（字面量 / 变量 = 0 位，裸 `_` = 1 位，`@fn` = fn 形参数量，`def 名字` = 1 位），点位数与数据量编译期校验。详见 [06-匹配](./06-匹配-MATCH.md) 与 [04-链模型 §5.1](./04-链模型-CHAIN.md)。

存储收编于链模型：`def` 是内置绑定的接收者（tee 语义——绑定后原值透传），无独立存储运算符。定案记录见 [design/09](../design/09-链上定义.md)。

## 核心符号速览

| 符号 | 唯一含义 | 示例 |
| --- | --- | --- |
| `->` | 传递：左侧 → 右侧接收者（唯一流向符号，仅链段使用） | `data -> @f`、`1 -> def x` |
| `=>` | 函数构造：形参 → 体 | `\ x => x * 2` |
| `\` | 构造前缀：开启函数定义 | `\ x => x * 2` |
| `@` | 调用：标记调用点（唯一调用标记） | `@f`、`data -> @f` |
| `_` | 占位：数据落点 / default 守卫 / 守卫内引用 | `-> @f, _ -> @g` |
| `def` | 定义站点：绑定上游数据到名字（内置功能），原值透传 | `1 -> def x` |
| `match` | 值分发：对单一被匹配值按分支列表多路分发 | `match x { 1 : "one" }` |
| `when` | 条件分发：多守卫布尔表达式列表，自上而下短路 | `when { x < 0 : … }` |
| `each` | 遍历：源逐元素流入体；带守卫形态 = 遍历 + 过滤 | `each xs { _ * 2 }`、`data -> each _ { … }` |
| `while` | 条件循环：守卫每轮重评，全假退出 | `while { @running : 体 }` |
| `:` | 分支分隔：分支左侧与体之间 | `_ > 0 : @incr` |
| `;` | 语义分号：数据未到终点，值在此丢弃 | `x -> @log;` |

完整分工与保留约束见 [02-符号](./02-符号-SYMBOLS.md)；全量文法见 [12-文法](./12-文法-GRAMMAR.md)。

## 快速示例

```cosat
# 定义 = 构造 + 流入 def；分支体泛化：常量分支免 lambda 包装
\ n => match n {
    0 : 0
    1 : 1
    _ : (n - 1 -> @fib) + (n - 2 -> @fib)
} -> def fib;

10 -> @fib -> @print;                # → 55

# 管道 + 参数重排（@\ 惯用形）+ 多返回值
data1, data2 -> @\ a, b => b, a -> @fn;   # → fn(data2, data1)

# 链上定义（tee）：d 绑定后原值继续流
data -> def d -> match _ {…}, d -> @log;

# 循环：表达式体收集（map）、遍历带守卫（filter）
each nums { _ * 2 } -> def doubled;
each nums { _ > 0 : @print }             # 仅正数元素流入 @print
```
