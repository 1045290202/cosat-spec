# Cosat 废案集：取代记录（2026-08-19/20 定案）

以下为旧定案形态被新提案取代的记录（对应定案规则现见 [04-链模型](../spec/04-链模型-CHAIN.md)、[05-函数](../spec/05-函数-FUNCTIONS.md)、[06-匹配](../spec/06-匹配-MATCH.md)、[07-循环](../spec/07-循环-LOOP.md) 对应章节）：

| 被取代形态 | 取代者 | 取代原因 |
| --- | --- | --- |
| 隐式调用 `data -> f`（站点裸标识符自动调用） | 显式调用 `data -> @f`；裸标识符站点编译错 | `@` 收敛为唯一调用标记：裸标识符 = 永远引用、`@` = 永远调用，传引用/传结果在文法层可区分（公理 3/5），并支撑点位数量校验模型 |
| `->` 兼任定义箭头（`\ x -> body`） | `=>` 专职定义（`\ x => body`），`->` 仅数据流 | 符号单一含义（公理 3）；嵌套管道中定义/流向视觉分离；与 JS/TS 箭头函数直觉对齐 |
| 分支 / 循环体必须是函数（裸字面量 / 算式作体编译错） | 体 = 接收点位匹配的任意表达式（字面量 0 位、`_` 表达式 1 位、`@fn` = 形参位） | 常量分支免包装（零 lambda 样板）；旧约束是点位模型的特例（函数 = 有接收点位的表达式）；点位编译期可算，无需类型系统 |
| 循环三形态（遍历 / 条件 / 站点） | 新增**遍历带守卫** `~ 源 { 守卫 : 接收者 }` | 遍历 + 过滤的惯用形免 lambda/match 包装（2026-08-20 定案） |
| 无多返回值；参数重排靠中转变量 | 体逗号表达式 = 参数组返回；`@\ a, b => b, a` 惯用形 + 纯重排 β-归约 | 正交组合既有原语（`@` + `\` + 参数组）零新符号；纯重排零闭包零调用零临时变量 |
| 旧禁 `data -> @fn`（单字符陷阱） | 新禁 `data -> fn`，`@` 为站点常态 | 陷阱消除方向反转：显式化使"缺 @"成为可编译检查的形态（防 typo 静默漂移的公理 5 新实例） |
