## 文法（EBNF）

```ebnf
each-expr     = "each" , source , block                 (* 遍历型：each src { 体 } *)
              | "each" , source , guard-block           (* 遍历带守卫型：each src { 守卫 : 体 … } *)
              | "each" , "_" , block ;                  (* 站点源：仅 data -> each _ { 体 } *)
while-expr    = "while" , guard-block ;                 (* 条件循环：while { 守卫 : 零参体 … } *)
source        = operand-banned ;                        (* 扫描到 { 止；内禁 -> ; , : *)
guard-block   = "{" , guard-branch , { guard-branch } , "}" ;
guard-branch  = guard , ":" , receiver ;
guard         = "_" | operand-with-"_" ;                (* 扫描到 : 止；each 守卫 _ = 当前元素；while 守卫禁 _，单独 _ 守卫 v1 编译错 *)
receiver      = operand | block ;                       (* each 供 1 值；while 供 0 值 *)
```

遍历型与遍历带守卫型的区分：块内首个 `:` 是否在配对 `}` 之前（扫描判定）。

## §7.3 each 与 while（体接收者化 + 泛化与带守卫形态）

> **术语**：`each` = 遍历家族（遍历 / 遍历带守卫 / 站点位，旧 `~` 带源形态），`while` = 条件循环（旧称条件型）；2026-08-22 起由双关键词取代单一 `~` 前缀（取代记录见 [10-废案](./10-废案-REJECTED.md)）。

**体 = 接收者**，泛化为接收点位匹配的任意表达式（同 [06-匹配](./06-匹配-MATCH.md)）：

| 型 | 形态 | 语义 |
| --- | --- | --- |
| 遍历型 | `each 源 { 接收者 }` | 逐元素流入体（= 遍历 / map / forEach） |
| **遍历带守卫型** | `each 源 { 守卫 : 接收者 … }` | 逐元素先绑给守卫 `_`，命中再流入体；全假即跳过（= 遍历 + 过滤） |
| 条件循环 | `while { 守卫 : 零参接收者 … }` | 反复判断：每轮重评守卫，命中→执行→回顶部；全假→退出（= while / 状态机） |
| 站点位 | `data -> each _ { 接收者 }` | 上游 = 源，元素流入体（§7.3.4） |

```cosat
each xs { \ x => x * 2 } -> def doubled;       # lambda 体：表达式体恒有值 → 恒收集
each xs { _ * 2 }                               # 泛化表达式体：_ = 元素接收点位
each xs { @log }                                # 函数引用体
each xs { \ x => { x -> @log; } }               # 块体尾分号 → 不收集（副作用遍历）
each xs { _ > 0 : @log }                        # 遍历带守卫：仅正数元素流入
while { @running : \ => { @tick; } };           # 条件循环：每轮重评 running，全假退出（外部状态驱动）
data -> each _ { \ x => x * 2 } -> @sum;        # 站点循环：源位 _ = 上游
```

- **词法**：keyword token（[01-词法](./01-词法-LEXICAL.md)），无前缀空格规则；不入优先级表（结构性关键词）；原 `~=` 式贪婪合并报错类随符号退役消失；
- **体形态约束**：体 = 接收点位匹配的表达式（each 提供 1 值，while 提供 0 值），点位不匹配编译错（`each xs { @twoArgFn }` ✕）；裸算式不含 `_` / `@fn` 时按 0 位处理——`each xs { x * 2 }` 中 x 未绑定，编译错；
- **收集开关 = 体的值出口**（语义分号原文适用于块体；非块体另有两条判定：泛化表达式恒收集、引用体语句位不收集）：见 §7.3.1；
- **`_` 与循环体**：lambda 体中元素经形参具名，弃名用零参；泛化表达式体中 `_` 为元素的引用型接收点位——循环自身不引入贯穿性 `_` 绑定；
- **值位穷尽**：值位使用的循环体必须有值出口，否则编译错。

## §7.3.1 体尾分号开关（lambda 块体适用）

`;` 的语义（数据未到终点、值被拦下）延伸到迭代维度：

| 体尾 | 语义 | 循环值 |
| --- | --- | --- |
| 无分号 | 块值流出（出口通向收集器） | 各次体块值组成的**数组**（≈ map） |
| 带分号 | 迭代值丢弃 | 无收集（≈ forEach，零收集开销） |

- 编译期由 Block.tail 判定，副作用循环不生成收集代码；空源 → `[]`；
- 体块值**一律收集**（空值也入列——理由见 [design/07](../design/07-循环.md)，筛选用守卫形态或库函数 filter）；
- 泛化表达式体本身即值 → 恒收集；引用体 `@log` 语句位不收集；
- **值位穷尽**：值位（链值位、参数组）使用的循环体必须有值出口——对齐 match 值位穷尽，防静默空值。

## §7.3.2 遍历型规则

| 规则 | 内容 |
| --- | --- |
| 体 | = 接收者：`\ x => …` / `\ => …` / 函数引用 `@f` / 泛化表达式；lambda 体内不使用 `_` |
| 源 | 扫描到 `{` 为止，内禁 `->` `;` `,` `:`（`,` 引参数组歧义；`:` 与被匹配值禁集对称）；扫描跳过配对括号与配对块；嵌套 `match` `when` `each` `while` `\` 须括号（同 [06 §7.1.2 B](./06-匹配-MATCH.md)）；**求值一次**；运行时须可迭代（数组/字符串/Map/Set/生成器），否则运行时错误 |
| 防误写 | 源为**比较表达式**或**数字/布尔字面量** → 编译错（数字引导用 range）；布尔变量源编译期无法识别，类型系统前限制 |

**循环体内的 match（泛化）**：lambda 体直接 `each xs { \ s => match s { … } }`；泛化体免包装 `each xs { match _ { … } }`——元素流入内层 match arg 位。

**源层 `_` 白名单（🔒 补案）**：源表达式**顶层**不得出现 `_` 作子表达式成分——`_ * _`、`_ * 2`、`f, _` 一律编译错；唯一合法 = 站点位单独 `_` 作源（§7.3.4）。嵌套前缀结构（须括号）内部的 `_` 属内层自有绑定，遮蔽外层、不受此限；**括号分组不改变层级归属**（`each (_ * 2) { }` 仍违规）。等价形态与理由见 [design/07](../design/07-循环.md)。

## 遍历带守卫型（独立形态）

```cosat
each xs {
    _ > 0 : each _ { @log }     # 外层元素 > 0 时，以该元素为源执行内层循环
}
```

**语义**：① 外层遍历源，当前元素绑定给守卫 `_`；② 守卫为真时元素流入分支体（点位匹配，同 match 分支体）；③ 全假的元素跳过（过滤语义）。

**已定案规则**：守卫内 `_` = 当前元素（引用型）；体 = 点位匹配表达式（1 位体消费元素，0 位体独立求值）；守卫扫描到 `:` 止。

**⏳ 待确认细则**（同构推定，实现前复核）：多守卫自上而下短路；单独 `_` 守卫 = 恒真 default；收集开关同遍历型（命中元素的体值入收集数组，未命中不入列）；值位使用时各守卫分支须有值出口；嵌套时内层 `_` 遮蔽外层。

## §7.3.3 while（条件循环）规则

| 规则 | 内容 |
| --- | --- |
| 循环语义 | 每轮自上而下**重评**守卫（与 match / when 求值一次的唯一差别）；命中→执行零参接收者→回顶部；全假→退出 |
| 体 | = 零参接收者（`\ => { … }`、`@f`、0 位表达式、when 嵌套），无数据随行 |
| `_` | 守卫内 `_` 未定义（同 when）；**单独 `_` 守卫 = 恒真 = 无限循环，v1 编译错**（随 break 解禁）；while 分支体内 `match _` 的 arg 位无数据可绑，需限制为 when 嵌套或零参表达式 |
| 结构 | 守卫 ≥ 1（`while { }` 编译错）；语句位 / 值位均可 |
| 风格 | 守卫每轮重评，副作用被放大——守卫保持纯 |
| 依赖 | 重绑定已定案为**无变异、遮蔽式 def**（[design/09](../design/09-链上定义.md)）：内部计数 / 累加等状态机形态不可写，用递归表达或待远期显式可变容器 ⏳；守卫由外部状态驱动的轮询不受影响 |

## §7.3.4 循环与链（链上完全公民）

站点循环的接收点 = 源位裸 `_`：

| 位置 | 写法 | 语义 |
| --- | --- | --- |
| 链值位 | `each xs { \ x => x * 2 } -> @sum;` | 循环值（数组）流入下游 |
| 站点位 | `data -> each _ { \ x => x * 2 } -> @sum;` | 源必须为单独 `_`；`data -> each xs { }` 断流编译错；`data -> each _, x -> @f` 编译错 |
| 参数组成员 | `data -> each _ { … }, x -> @f;` | `f(loop(data), x)` |
| while 入链 | `data -> while { 守卫 }` | ✕ 守卫不消费流数据 |

- 段判定：区间内 `each` 且源为 `_` → 循环站点段；段扫描跳过配对块；
- 合并段 `_` 引用计数：**源位 `_` 计一次**（元素绑定在体形参 / 体 `_` 引用位上，不计）；
- 生成层：lambda 体元素绑定在体形参；泛化体 `_` 替换为合成元素名；仅源位 `_` 与合并段 `_` 需合成名（`$src0` 等），禁字面 `_` 输出。

## §7.3.5 综合示例

```cosat
each nums { _ * 2 } -> def d;                 # 泛化体收集为数组
each nums { @log };                           # 引用体：逐元素调用，不收集
0 -> def i; 0 -> def sum;
while { @running : \ => { @step; } };         # 条件循环：外部状态驱动（无内部变异；状态机走递归）
data -> each _ { \ x => x * 2 } -> @sum;      # 站点循环，循环值流入下游
```

## §7.3.6 禁写速查

| 写法 | 判定 | 说明 |
| --- | --- | --- |
| `each xs { x * 2 }` | ✕ | x 未绑定——用 `_ * 2`（泛化）或 `\ x => x * 2`（lambda） |
| `each xs { _ * 2 }` | ✓ | 泛化表达式体 |
| `each i < 10 { … }` | ✕ | 源是比较式 → 用 while |
| `each 5 { … }` | ✕ | 数字字面量非源（repeat-N 搁置，类型系统期统一解禁"数字即范围"） |
| `while { _ : \ => { A; } }` | ✕ | `_` 守卫 = 无限循环，v1 禁 |
| `(each xs { \ x => { x -> @log; } }) -> def r;` | ✕ | 值位循环体必须有值出口 |
| `each each xs { } { }` | ✕ | 嵌套前缀结构须括号 |
| `data -> each xs { }` | ✕ | 站点位循环源必须 `_` |
| `each _ * _ { }` / `data -> each _ * 2 { }` | ✕ | 源层 `_` 禁作子表达式成分；用链分解或变量中转 |
| `each xs, y { }` | ✕ | 源内禁 `,` |
| `data -> each _, x -> @f` | ✕ | 站点位源仅限单独 `_` |
| `data -> while { 守卫 }` | ✕ | while 不可入链 |
| `each xs { @twoArgFn }` | ✕ | 点位不匹配（2 位 ≠ 1 元素） |
| `each xs { _ > 0 : @twoArgFn }` | ✕ | 遍历带守卫：体点位不匹配 |

## §7.3.7 实现依赖与顺序

Token 空白/span → Block.tail 字段 → 接收点位计数（AST 附 `receive_points` 字段）→ 解析上下文传递（`_` 深度与遮蔽）→ 遍历型 → 遍历带守卫型 → while 条件循环（重绑定已定案为无变异遮蔽，不再阻塞，见 [design/09](../design/09-链上定义.md)）；break/continue 与 `_` 守卫解禁随后（plain break = 停止并以此前收集为数组值）。分支体与循环体共用同一套 β-内联归约实现。
