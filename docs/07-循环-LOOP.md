## §7.3 `~` = 反复版 `?`（体接收者化 + 体泛化与带守卫形态）

判定机制与 `?` 同构（`~` 后紧跟 `{` → 条件型；expr + `{` → 遍历型；`~` 无中缀用法）。**体 = 接收者**，泛化为接收点位匹配的任意表达式（同 [06-匹配](./06-匹配-MATCH.md)）：

| 型 | 形态 | 语义 |
| --- | --- | --- |
| 遍历型 | `~ 源 { 接收者 }` | 逐元素流入体（= 遍历 / map / forEach） |
| **遍历带守卫型** | `~ 源 { 守卫 : 接收者 … }` | 逐元素先绑给守卫 `_`，命中再流入体；全假即跳过该元素（= 遍历 + 过滤） |
| 条件型 | `~ { 守卫 : 零参接收者 … }` | 反复判断：每轮重评守卫，命中→执行→回顶部；全假→退出（= while / 状态机） |
| 站点位 | `data -> ~ _ { 接收者 }` | 上游 = 源（源位裸 `_`），元素流入体（§7.3.4） |

```cosat
~ xs { \ x => x * 2 } >> def doubled;          # lambda 体：表达式体恒有值 → 恒收集
~ xs { _ * 2 }                                  # 泛化表达式体：_ = 元素接收点位
~ xs { @log }                                   # 函数引用体
~ xs { \ x => { x -> @log; } }                  # 块体尾分号 → 不收集（副作用遍历）
~ xs { _ > 0 : @log }                           # 遍历带守卫：仅正数元素流入
~ { i < 10 : \ => { i -> @log; i + 1 >> i; } }  # 条件型 = while
data -> ~ _ { \ x => x * 2 } -> @sum;           # 站点循环：源位 _ = 上游
```

- **词法**：前缀空格规则同 `\` `?`（[01-词法](./01-词法-LEXICAL.md)）；不入优先级表（结构性前缀）；贪婪吞并使 `~=` 等组合自动报错（天然隔离）；
- **体形态约束**：体 = 接收点位匹配的表达式（遍历型提供 1 值 = 当前元素；条件型提供 0 值）。点位不匹配编译错（`~ xs { @twoArgFn }` ✕）；裸算式不含 `_` / `@fn` 时按 0 位处理——元素未被消费，`~ xs { x * 2 }` 中 x 是未绑定标识符，编译错；
- **收集开关 = 体的值出口**（语义分号原文适用，无需专门规则）：见 §7.3.1；
- **`_` 与循环体**：lambda 体中元素经形参具名（`\ x =>`），弃名用零参；泛化表达式体中 `_` 为元素的引用型接收点位——循环自身不引入贯穿性 `_` 绑定；
- **值位穷尽**：值位使用的循环体必须有值出口，否则编译错。

## §7.3.1 体尾分号开关（lambda 块体适用）

`;` 的语义（数据未到终点、值被拦下）延伸到迭代维度：

| 体尾 | 语义 | 循环值 |
| --- | --- | --- |
| 无分号 | 块值流出（出口通向收集器） | 各次体块值组成的**数组**（≈ map） |
| 带分号 | 迭代值丢弃（数据未到终点） | 无收集（≈ forEach，零收集开销） |

- 编译期由 Block.tail 判定，副作用循环不生成任何收集代码；空源 → `[]`；
- 体块值**一律收集**（空值也入列——静默跳过属被否决的隐式魔法，筛选用库函数 filter）；
- 泛化表达式体（`_ * 2` 等）本身即值 → 恒收集；引用体 `@log` 语句位不收集；
- **值位穷尽**：值位（`>>` 右、链值位、参数组）使用的循环体必须有值出口，否则编译错——对齐 match 值位必须含 `_` 穷尽，防静默空值。

## §7.3.2 遍历型规则

| 规则 | 内容 |
| --- | --- |
| 体 | = 接收者：`\ x => …`（单参收当前元素）/ `\ => …`（弃元素）/ 函数引用 `@f` / 泛化表达式（含 `_` 接收点位或 0 位表达式）；lambda 体内不使用 `_`（形参具名） |
| 源 | 扫描到 `{` 为止，内禁 `->` `>>` `;` `,`（循环必跟块，`,` 只可能引向参数组歧义）；扫描跳过配对括号与配对块；嵌套 `?` `\` `~` 须括号（内层 `{` 吞并，同 [06-匹配 §7.1.2 B](./06-匹配-MATCH.md)）；**求值一次**；运行时须可迭代（数组/字符串/Map/Set/生成器），否则运行时错误 |
| 防误写 | 源为**比较表达式**或**数字/布尔字面量** → 编译错（`'~' on a comparison: use the guard form '~ { … }'`；数字引导用 range）；布尔变量源编译期无法识别，类型系统前限制 |

**循环体内的 match（泛化）**：lambda 体直接 `~ xs { \ s => ? s { … } }`；泛化体免包装 `~ xs { ? _ { … } }`——元素流入内层 match arg 位（`? _` = 1 接收点位）。

**源层 `_` 白名单（🔒 补案）**：源表达式**顶层**不得出现 `_` 作子表达式成分——`_ * _`（两处引用，违反恰好一次）、`_ * 2`、`f, _` 一律编译错，无论引用次数；唯一合法的源层 `_` = 站点位**单独 `_` 作源**（§7.3.4，上游绑定，计引用一次）。嵌套前缀结构（须括号）内部的 `_` 属内层自有绑定（match 默认守卫 / 守卫表达式 / lambda 形参 / 内层循环元素），遮蔽外层、不计引用、不受此限——`~ (? x { 1 : { A } _ : { B } }) { 体 }` 合法；**括号分组不改变 `_` 层级归属**（`~ (_ * 2) { }` 仍违规）。理由：① 单字符陷阱预防（`~ _ { }` 与 `~ _ * 2 { }` 一字之差语义大变）；② 需求全部有更清晰等价形态——`data -> @double -> ~ _ { 体 }`（站点分解）、`data -> ? _ { … } -> ~ _ { 体 }`（match 选源接续，两段各自绑定 `_`）、`data >> def d; ~ d * 2 { 体 }`（变量中转）；③ 从严到宽安全演进。

## 遍历带守卫型（独立形态）

```cosat
~ xs {
    _ > 0 : ~ _ { @log }        # 外层元素 > 0 时，以该元素为源执行内层循环
}
```

**语义**：① 外层遍历 xs，当前元素绑定给守卫 `_`；② 守卫为真时，当前元素流入分支体（体按接收点位匹配，同 match 分支体）；③ 所有守卫全假的元素**跳过**（过滤语义）。

**已定案规则**：守卫内 `_` = 当前元素（引用型）；体 = 点位匹配表达式（1 位体消费元素，0 位体独立求值）；守卫扫描到 `:` 止（同条件型）。

**⏳ 待确认细则**（同构推定，实现前复核）：多守卫自上而下短路（同条件型）；单独 `_` 守卫 = 恒真 default；收集开关同遍历型（命中元素的体值入收集数组，未命中元素不入列）；值位使用时各守卫分支须有值出口；嵌套时内层 `_` 遮蔽外层。

## §7.3.3 条件型规则

| 规则 | 内容 |
| --- | --- |
| 循环语义 | 每轮自上而下**重评**守卫（与 `?` 求值一次的唯一差别）；命中→执行零参接收者→回顶部；全假→退出 |
| 体 | = 零参接收者（`\ => { … }`、函数引用 `@f`、0 位表达式、cond 型嵌套 `? { … }`），无数据随行 |
| `_` | 守卫内 `_` 未定义（同 cond 型 match）；**单独 `_` 守卫 = 恒真 = 无限循环，v1 编译错**（随 break 解禁，届时为 game loop 惯用形）；条件型分支体内 `? _` 的 arg 位无数据可绑——`_` 未定义，需限制为 cond 型嵌套或零参表达式 |
| 结构 | 守卫 ≥ 1（`~ { }` 编译错）；语句位 / 值位均可 |
| 风格 | 守卫每轮重评——守卫内 `@` 调用副作用被放大，守卫保持纯 |
| 依赖 | 条件循环依赖可变状态 → **阻塞于重绑定定案**（`值 >> 裸名`，与 [09-速查](./09-速查-CHEATSHEET.md) 链式 `def` 待定同案） |

## §7.3.4 循环与链（链上完全公民）

本节为公理 6（接收点显式）在循环上的实例：**站点循环的接收点 = 源位裸 `_`**。

| 位置 | 写法 | 语义 |
| --- | --- | --- |
| 链值位 | `~ xs { \ x => x * 2 } -> @sum;` | 循环值（数组）流入下游 |
| 站点位 | `data -> ~ _ { \ x => x * 2 } -> @sum;` | **源必须为单独 `_`**（源层 `_` 白名单见 §7.3.2）：上游绑定源位，元素流入体接收者；`data -> ~ xs { }` 上游断流编译错；`data -> ~ _, x -> @f` 编译错（参数组不可作源） |
| 参数组成员 | `data -> ~ _ { … }, x -> @f;` | `f(loop(data), x)` |
| 条件型入链 | `data -> ~ { 守卫 }` | ✕ 守卫不消费流数据（同 match cond 型断流规则） |

- 段判定：区间内 `~` 且源为 `_` → 循环站点段；段扫描跳过配对块（match 已有同需求）；
- 合并段 `_` 引用计数：**源位 `_` 计一次**（元素绑定在体形参 / 体 `_` 引用位上，不计）；
- 生成层：lambda 体元素绑定在体形参（原样输出形参名即可）；泛化体 `_` 替换为合成元素名；仅源位 `_` 与合并段 `_` 需合成名（`$src0` / 合并段临时名），禁字面 `_` 输出。

## §7.3.5 综合示例

```cosat
~ nums { _ * 2 } >> def d;                    # 泛化体收集为数组
~ nums { @log };                              # 引用体：逐元素调用，不收集
0 >> def i; 0 >> def sum;
~ { i < 10 : \ => { sum + i >> sum; i + 1 >> i; } };   # 条件型（依赖重绑定定案）
data -> ~ _ { \ x => x * 2 } -> @sum;         # 站点循环，循环值流入下游
```

## §7.3.6 禁写速查

| 写法 | 判定 | 说明 |
| --- | --- | --- |
| `~xs { }` / `~{ c : \ => { A; } }` | ✕ | 前缀后必须空格 |
| `~ xs { x * 2 }` | ✕ | x 未绑定：元素未被消费——用 `_ * 2`（泛化）或 `\ x => x * 2`（lambda） |
| `~ xs { _ * 2 }` | ✓ | 泛化表达式体（元素经 `_` 接收点位消费） |
| `~ i < 10 { … }` | ✕ | 源是比较式 → 用条件型 |
| `~ 5 { … }` | ✕ | 数字字面量非源（repeat-N 糖搁置，类型系统期统一解禁"数字即范围"） |
| `~ { _ : \ => { A; } }` | ✕ | `_` 守卫 = 无限循环，v1 禁 |
| `(~ xs { \ x => { x -> @log; } }) >> def r;` | ✕ | 值位循环体必须有值出口 |
| `~ ~ xs { } { }` | ✕ | 嵌套前缀结构须括号 |
| `data -> ~ xs { }` | ✕ | 站点位循环源必须 `_`，上游断流 |
| `~ _ * _ { }` / `data -> ~ _ * 2 { }` | ✕ | 源层 `_` 禁作子表达式成分（`_ * _` 另犯两处引用）；用链分解或变量中转（§7.3.2 白名单） |
| `~ xs, y { }` | ✕ | 源扫描内禁 `,`（参数组不可作源） |
| `data -> ~ _, x -> @f` | ✕ | 站点位源仅限单独 `_`，参数组不可作源 |
| `data -> ~ { 守卫 }` | ✕ | 条件型不可入链 |
| `~ xs { @twoArgFn }` | ✕ | 点位不匹配（2 位 ≠ 1 元素） |
| `~ xs { _ > 0 : @twoArgFn }` | ✕ | 遍历带守卫：体点位不匹配 |

## §7.3.7 实现依赖与顺序

Token 空白/span（前缀空格规则落地前置，[01-词法](./01-词法-LEXICAL.md) 已知问题提升为硬依赖）→ Block.tail 字段（收集开关判定依据，[08-语句](./08-语句-STATEMENTS.md) 已注记）→ **接收点位计数**（AST 附 `receive_points` 字段，与 [04-链模型 §5.1](./04-链模型-CHAIN.md) 点位模型共用）→ 解析上下文传递（`_` 深度与遮蔽）→ **遍历型**（不依赖重绑定，可先行）→ 遍历带守卫型（复用条件型守卫解析器）→ 重绑定定案 → **条件型**（守卫解析器与 `?` cond 型共享，同批实现）；break/continue 与 `_` 守卫解禁随后（plain break = 停止并以此前收集为数组值）。分支体与循环体共用同一套 β-内联归约实现。
