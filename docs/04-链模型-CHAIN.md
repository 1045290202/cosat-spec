## §5 链 = 值 段\*

这是核心文法，统一了零参 / 单参管道 / 多参调用三种形态。

- **值**：空（零参链首）、表达式、或逗号分隔的参数组；
- **段**（两种）：
  - **直传段** `-> @f`：上游整体流向函数并调用（多值上游 = 多参调用）。站点必须带 `@` 显式调用；
  - **合并段** `-> 参数组 -> @f`：上游按点位填入参数组（`_` 位或 `@fn` 形参位），与成员合并后流向函数。

```cosat
data -> @f;                       # → f(data)              值=data，直传
a, b -> @f;                       # → f(a, b)              值=参数组，直传即多参
data -> @f -> _, x -> @g;         # → g(f(data), x)        直传 + 合并
data -> @h, _ -> @g;              # → g(h(), data)         合并段成员可为 @ 表达式
data, fn -> @g;                   # → g(data, fn)          裸标识符 = 传引用
data, @fn -> @g;                  # → g(data, fn())        @ = 调用，结果入组
```

## §5.1 点位分配模型

遇到 `->` 时，编译器对**每一跳**执行三步。`->` 左侧参数按**从左到右**的顺序分配给右侧接收点位——每个 `@fn` 消耗 fn 形参数量个左侧参数，`_` 消耗 1 个：

**第一步：扫描右侧，收集所有接收点位**

| 表达式类型 | 暴露点位数 |
| --- | --- |
| `@fn` / `@@fn` / `@@@fn` … | fn 的形参数量（由 fn 定义确定，点位不跨层） |
| `_` | 1（原样直通位） |
| 裸标识符 `fn`（无 `@`） | 0（引用，不消耗参数；❓ 待定案，倾向方案 A——见 [05-函数 §6.6 开放问题 1](./05-函数-FUNCTIONS.md)） |
| 数字 / 字符串字面量 | 0（值，不消耗参数） |

嵌套 `? _ { … }` / `~ _ { … }` 暴露 1 位（arg 位 / 源位），嵌套 cond 型 / 定源循环暴露 0 位——完整计数表见 [06-匹配](./06-匹配-MATCH.md)。

**第二步：校验点位总数 = 左侧参数数量**。不等则编译错（参数数量不匹配）。

**第三步：从左到右逐表达式处理**——遇到 `@fn` 按 fn 形参顺序取走对应数量的剩余左侧参数并求值，结果原位替换；遇到 `_` 取 1 个参数原样保留；遇到 0 位表达式直接求值。全部求值后结果组成参数组，流入下一段。

```cosat
data1, data2, data3 -> @fn1, _ -> @fn2;
# 假设 fn1 取 1 参：
# 第一跳右侧点位：@fn1(1) + _(1) = 2 ≠ 左侧 3 → 编译错（点位校验按跳进行，不跨 -> 累加）
```

```cosat
data1, data2 -> @fn1, _ -> @fn2;      # 假设 fn1 取 1 参、fn2 取 2 参
# 第一跳（合并段 @fn1, _）：点位 2 = 左侧 2 ✓
#   @fn1 消耗 data1 → r1 = fn1(data1)；_ 保留 data2 → 合并组 [r1, data2]
# 第二跳：[r1, data2] -> @fn2 → fn2(fn1(data1), data2)
```

多 `@fn` 的结果组合：同一参数组内各自消耗参数后结果组成参数组流向下游（`data1, data2, data3, data4 -> @fn1, _, @fn2, @fn3;`，fn1 / fn2 / fn3 各取 1 参 → `[fn1(data1), data2, fn2(data3), fn3(data4)]` 流入下游）；独立链段则上一段结果流向下一段（`data1 -> @fn1 -> @fn2` → `fn2(fn1(data1))`）。

> ❓ `data -> @fn1, data2 -> @fn2` 按本节点位模型推导为 `fn2(fn1(data), data2)`（首段 `@fn1, data2` 为合并段）。该推导为工作结论，待最终定案确认。

## `->` 统一语义

`->` 全语言只有一个含义——**把左边的东西送到右边的目的地**（公理 2"目的地殿后"的箭头实例），且仅用于链段一处，职责纯化：

| 位置 | 左侧 | 右侧目的地 | 数据在右侧的可见形式 |
| --- | --- | --- | --- |
| 链段 `值 -> @f` | 数据 | 接收者 | f 的形参表 / 裸 `_`（arg 位 / 源位）/ 泛化表达式接收点位 |

**段的本质 = 上游 × 接收者**（公理 6 接收点显式）：段判定规则均为接收点规则的实例。

## 段判定规则

lookahead 到下一个 `->` 或 `;`，封闭无歧义：

| 区间内容 | 判定 |
| --- | --- |
| 含逗号或 `_` | 合并段（参数组） |
| `@标识符` / `@@标识符` | 直传段（显式调用） |
| 裸标识符 / dot 链 | **编译错**（缺少 `@`） |
| 裸 `@`（无标识符） | 编译错（站点位禁裸 `@`） |
| `~` 且源为 `_` | 循环站点段（`data -> ~ _ { 体 }`，见 [07-循环 §7.3.4](./07-循环-LOOP.md)）；段扫描跳过配对块 |
| `? _ { … }` | match 段（上游 = 被匹配值，见 [06-匹配](./06-匹配-MATCH.md)） |

## `_` 绑定模型

`_` 的角色为"**原样直通点位**"（上游数据也可直接被 `@fn` 的形参位消耗）：

- 合并段内参数组成员（含成员表达式内部，如 match arg 位 `_`）中的 `_` 为同一绑定的引用；
- **`_` 恰好被引用一次**：顶层成员位或成员表达式内，合计一处；零处 = 不需要 `_`（可直接由 `@fn` 消耗上游），多处 = 编译错（`_, _` / `? _ {…}, _` 均非法）；
- **多视图需求用普通变量中转**：`data >> def d; d -> ? _ {…}, d -> @fn;`——`_` 单次引用（match arg），`d` 是普通变量可无限次引用；隐式单接收 + 显式多引用，分工清晰；
- **求值顺序**：参数组成员严格从左到右求值；`_` 绑定本身不可变（成员含变异调用时注意顺序依赖）；
- **禁用多引用的理由**：① 隐式 mutation 风险（先求值成员修改值，后续成员读到变化）；② 功能可由变量中转完全替代；③ 从严到宽是安全演进（将来放开多引用不破坏任何既有代码，反之则是 breaking change）；先例：Kotlin `it` / Clojure `%` 支持多引用，Scala `_`（每处独立绑定）因语义混乱被弃用——Cosat 选择最保守形态；
- **内层遮蔽**：内层 match 的 `_` 绑定（arg 位 + 守卫位）遮蔽外层参数组的 `_`。

## match 与链的结合

- **match 段**：`data -> ? _ { 分支 }`——上游数据为被匹配值，命中支路值为段输出，可继续流：`data -> ? _ { … } -> @next;`；
- **match 作为参数组成员**：`data -> ? _ { … }, x -> @fn;`——match 表达式（`_` 引用计一次）与 x 合并 → `fn(match(data), x)`；
- **切分判定**（块 `}` 之后的 token）：`;` / `>>` → match 段结束；`->` → match 段输出流入后续段；`,` → match 是参数组首成员，参数组继续，后须 `-> @函数` 收尾；
- cond 型不可入链（守卫不消费流数据，入链即点位不匹配 / 断流报错），限语句位 / 值位。

## 禁止的写法 🚫

| 写法 | 判定 | 原因 |
| --- | --- | --- |
| `data -> fn` | ✕ | 站点位缺少 `@`（显式调用） |
| `data1 -> @f1 -> data2, data3 -> @f2;` | ✕ | 第二跳点位不匹配（0 位 ≠ 1 值），数据断流 |
| `data1 -> @f1, data2, data3 -> @f2;` | ⏳ 待复核 | 段扫描确定性解析为合并段 `@f1, data2, data3`（上游填 @f1 位），歧义已消灭，禁写是否解除待实现确认 |
| `a, b -> { … }` | ✕ | 站点位禁块；实参/形参、执行体/函数体文法不可区分（已否决的 lambda 形态） |
| `data -> _, _ -> @fn;` | ✕ | `_` 多处引用；同值双传用中转：`data >> def d; d, d -> @fn;` |
| `data -> ? _ {…}, _ -> @fn;` | ✕ | `_` 两处引用（match 内 + 顶层）；用 `data >> def d; d -> ? _ {…}, d -> @fn;` |
