## §3 符号分工表

| 符号 | 唯一含义 | 方向 / 示例 |
| --- | --- | --- |
| `>>` | **存储**：值 → 名字 | `1 >> def x` |
| `->` | **数据流**：把左边的东西送到右边的接收者。仅用于链段（定义箭头由 `=>` 专职） | `data -> @f` |
| `=>` | **函数构造**：形参 → 体（函数定义专用箭头） | `\ x => x * 2` |
| `\` | **构造前缀**：开启函数定义（形参 + 体 → 函数值） | `\ x => x * 2` |
| `@` | **调用**：裸标识符永远是引用，`@` 标记该标识符是一个调用 | `@f`、`data -> @f` |
| `_` | **占位**：上游数据落点（合并段 / match arg 位 / 循环源位）/ match 默认守卫 / 守卫表达式内被匹配值引用 / 泛化体内被匹配值、循环元素的引用型绑定 | `data -> @f, _ -> @g` |
| `?` | **分支**：前缀 = match 多路分发（🔒 定案）；中缀 = `? :` 三元（⏳ 待定） | `? { 守卫 : 体 }` |
| `~` | **循环**：遍历型 / 遍历带守卫型 / 条件型 / 站点位 | `~ xs { _ * 2 }` |
| `.` | 成员访问（上一 token 为标识符时；否则小数点） | `@obj.method` |
| `==` | 相等（严格相等） | `a == b` |
| `#` / `#$ $#` | 注释 | — |
| `;` | **流动分隔（语义分号）**：数据未到终点，值在此丢弃、流继续；块尾无分号 = 值的出口 | `x -> @log;` vs `{ x * 2 }` |
| `:` | **分支分隔**：分支左侧（判定）与分支体（接收者）之间；守卫扫描到 `:` 为止 | `_ > 0 : \ x => …` |
| `def` | 定义目的地标记 | `>> def x` |

## 符号禁区（未来特性选号约束）🔒

- 模块/命名空间路径**不得用 `\`**（词法冲突），锁定 `.` 或 `::`；
- 装饰器/注解**不得用 `@`**（已占用为调用标记），`#` 亦不可（注释）；
- **`=` 已被 `=>` 前导消费**：不存在独立 `=` 赋值语义，存储恒走 `>>`；未来 `=` 系组合符（`==` 除外）须避开 `=>` 贪婪匹配；
- 未占用符号池：`::` `|` `&` `%` `^` `'` `[` `]` 等（`(` `)` 已占用为括号分组 / 动态站点 / 嵌套前缀结构消歧，不入池），新特性启用前先查本表（`,` 已占用为参数组分隔）；`~` 已被循环占用；`:` 已被分支分隔占用——类型标注与 `? :` 三元启用时**错位共存**（类型在形参后、`=>` 前：`\ x: T => …`；三元在中缀表达式内；守卫内禁三元），启用时需复核；`|` `&` `^` `%` 为未来逻辑/位/模二元运算的仅存候选，原则上不作前缀消费。
