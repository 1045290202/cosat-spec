## §7.1 match

**形态**：`?` 前缀 + 分支列表块；**分支 = `分支左侧 : 接收者`**：

```cosat
? {                                  # cond 型：条件分发（无数据随行，体须 0 接收点位）
    x < 0   : "负" -> @log;
    y > 10  : "正" -> @log;
    _       : C
}

? x {                                # switch 型：对单一被匹配值分发（值流入体）
    1      : "精确命中" -> @log;
    _ > 99 : "大数: " + _
    _      : "其他" -> @log;
}
```

**核心语义（接收点位匹配）**：分支体 = **接收者**，但不必是函数——任何表达式按**接收点位数**参与匹配，编译期校验与数据量相等（公理 6 的泛化）。分支体就是 `->` 右侧的一种接收者：点位收集与数量校验机制和链段（[04-链模型 §5.1](./04-链模型-CHAIN.md)）完全一致，差别仅在数据来源——链段左侧是显式参数列表，match 是隐式的被匹配值：

| 分支体 | 接收点位 | 行为 |
| --- | --- | --- |
| 字面量 / 变量引用 / 不含 `_`、`@fn` 的表达式 | 0 | 独立求值，结果 = 分支值（数据不进入；switch 型可直接引用被匹配值名字，如 `"大数: " + x`） |
| `@fn`（fn 取 N 参） | N | 数据（或其前 N 个）按形参顺序流入并调用 |
| `@@fn` | N | 同 `@fn`——点位不跨层，外层 `@` 只追加零参调用 |
| 含 `_` 的表达式（`_ + 1`） | 1 | `_` 绑定数据，表达式求值 |
| lambda 字面量 `\ x => …` | 形参数量 | 体位自动应用（❓ 见 [05-函数 §6.6](./05-函数-FUNCTIONS.md) 开放问题 3） |
| 嵌套 `? _ { … }` / `~ _ { … }` | 1（arg 位 / 源位） | 数据流入内层结构，免 lambda 包装 |
| 嵌套 cond 型 `? { … }` / 定源循环 | 0 | 同字面量 |

```cosat
# 点位校验
? x { 1 : @twoArgFn }                # ✕ 2 点位 ≠ 1 值，编译错
? x { _ > 0 : @process }             # ✓ @process 取 1 参，消耗被匹配值

# 分支体嵌套 match（外层匹配值流入内层 arg 位）
? x {
    _ > 0 : ? _ {
        1     : "exact one"
        _ > 99: "huge"
        _     : "positive"
    }
    _     : "non-positive"
}
```

**lambda 仍不可替代的场景**：闭包捕获（内层引用外层变量）、多语句体（语义分号控制）、显式命名参数（`\ x =>` 的名字比 `_` 清晰）。

### 规则

- `branch → 分支左侧 ":" receiver`；receiver = 点位匹配的任意表达式；
- 判定：`?` 位于**值位开头**（语句首、`>>` 后、`->` 后、`,` 后）即前缀 match，后必须紧跟 `{`（cond 型）或表达式 + `{`（switch 型）；`?` 前一 token 是操作数则为中缀（见 §7.2）；
- **守卫扫描到 `:` 为止**：守卫内禁 `:` `->` `>>` `;`（及未来 `? :` 三元）——守卫自定界；
- **守卫求值**：自上而下、第一为真即命中，只执行命中分支（短路）；switch 型被匹配值**求值一次**；
- **体形态与语义分号**：语句位分支可用单行体，分支间以 `;` 分隔（值丢弃，纯效果分发）；**值位分支体必须有值**——块体 lambda 以 `}` 为值出口，泛化表达式体本身即值；块体分支间无分隔符（`}` 闭合）；
- **分支值 = 体应用于数据**（switch：被匹配值按点位流入）/ **体调用或求值**（cond：0 位）；
- **零参形态** `\ => 表达式`：分支不需要被匹配值时不造形参（多语句体仍用 `\ => { … }`）；
- **应用与选择正交（由引用/调用区分接管）**：体写 `@pass` = 应用（`pass(被匹配值)`）；写 `pass`（裸引用，0 位）= 选择（分支值 = pass 本身，未应用）——真路由用后者：

```cosat
data -> (? { _ > 0 : pass  _ : fail });    # 路由：match 选出函数，data 流入选中者
```

- **函数引用复用**：`_ > 0 : @incr`——分支路由到已有函数（策略 / 路由表）；
- **分发形态与性能**：字面 `\ …` = **静态分发**——生成器 β-内联（字面 lambda 恰好应用一次，直接展开，零闭包分配零调用）；引用 / 泛化表达式 = 直接嵌入或动态分发——编译期不可内联，单赋值 `def` 可传播回字面，运行时单态由内联缓存兜底；**文法即分发选择权**；
- **use-based 穷尽**：值位 match 必须含单独 `_` default 且各分支有值出口（编译错：judgement used as value must be exhaustive）；语句位可省 `_`（全假即跳过）；
- 无 fallthrough；型内禁混；分支 ≥ 1；
- **生成策略**：字面体 β-内联展开；泛化体直接嵌入（`_` 替换为被匹配值名）；守卫顺序映射条件链，`_` 对应最终分支；值位以隔离作用域包裹取值。

## §7.1.1 switch 型：分支左侧与 `_` 角色

被匹配值表达式扫描到 `{` 为止（内禁 `->` `>>` `;` `:`），**求值一次**存为被匹配值。分支左侧（扫描到 `:` 为止判定）三种形态 = 被匹配值的三种**用法**：

| 分支左侧 | 语义 |
| --- | --- |
| 字面量（number / string / bool） | 严格相等比较（数据不需名字，`_` 不出场） |
| 含 `_` 的守卫表达式 | `_` 绑定为被匹配值，求值为真即命中；**必须引用 `_`**，否则属 cond 型（型内禁混，编译错） |
| 单独 `_` | default，恒命中 |

- **裸标识符分支禁止**：比较还是绑定在无类型系统下真歧义，v1 编译错；
- **`_` 角色（全语言出场位）**：**位置型**（合并段点位 / match arg 位 / 循环源位：数据落点，恰一次）+ **引用型**（switch 守卫表达式内：被匹配值引用，次数不限、遮蔽外层、不可重绑定；泛化体内 `_` 亦为引用型，如体 `_ + 1`、循环体 `_ * 2`）；lambda 体内部不使用 `_`——数据经形参具名（`\ v =>`）或零参弃用；
- **`_` 绑定层级与遮蔽**：体 / 守卫中的 `_` 绑定**当前层级**的数据（被匹配值 / 循环元素），不是外层 `_` 的延续；嵌套层级中内层 `_` 遮蔽外层：

```cosat
~ xs {                           # 外层元素 = _（循环绑定）
    ? _ {                        # _ 遮蔽外层，绑定被匹配值
        _ > 0 : ~ _ {            # _ 遮蔽 match，绑定循环源
            @log                 # 此处 _ = 内层循环元素
        }
    }
}
```

- **match 双型定位**：cond 型管多条件任意表达式，switch 型管单值分发；模式匹配远期挂 switch 型（形态不变）⏳。

## §7.1.2 match 全变体清单

### A. 位置变体

| 位置 | 写法 | 约束 |
| --- | --- | --- |
| 语句位 | `? { … };` / `? x { … };` | 单行体分支间 `;`（值丢弃）；`_` 可省（全假跳过） |
| `>>` 右侧（值位） | `? x { _ > 0 : _  _ : 0 } >> def r;` | 必须含单独 `_` default + 各分支有值出口 |
| 链值位 / 参数组成员 | `? { … } -> @f;`、`? { … }, x -> @g;` | 同上，必须穷尽 |
| match 段（链内） | `data -> ? _ { 分支 } -> @next;` | 上游 = 被匹配值，分支值可继续流（切分判定同 [04-链模型](./04-链模型-CHAIN.md)） |
| 路由（选择不应用） | `data -> (? { _ > 0 : pass  _ : fail });` | 分支值 = pass/fail 本身（0 位引用），data 流入选中函数（动态站点括号规则） |
| 嵌套 | 守卫内 / 被匹配值（须括号） | 自然递归 |

### B. 被匹配值形态（switch 型）与括号规则

| 形态 | 写法 | 括号 |
| --- | --- | --- |
| 标识符 / dot 链 | `? x { … }`、`? obj.f { … }` | 不需要 |
| 裸表达式 | `? x + 1 { … }` | **允许不加括号**（扫描到 `{` 为止） |
| `@` 表达式 | `? @f { … }` | 不需要 |
| 含 match / lambda / 循环的嵌套前缀结构 | `? (? x { … }) { … }` | **必须加括号**（内层 `{` 被外层吞并） |

被匹配表达式内**禁止** `>>` `->` `;` `:`（语句级与分支级符号，遇到即编译错）。

### C. 守卫 / 分支左侧规则（分型）

| 写法 | cond 型 `? { … }` | switch 型 `? x { … }` |
| --- | --- | --- |
| 布尔表达式（任意变量） | ✓ 核心形态 | ✕（必须含 `_`，否则属 cond 型） |
| 字面量 | ✕（truthy 恒真，逼用 switch 型） | ✓（严格相等比较） |
| 含 `_` 的表达式 | ✕（cond 型无被匹配值，`_` 未定义） | ✓（`_` 绑定被匹配值；必须引用） |
| 单独 `_` | ✓ default | ✓ default |
| 裸标识符 | ✕（比较/绑定歧义） | ✕（同左） |

### D. 分支体（泛化）

体 = 接收点位匹配的表达式（§7.1 点位表）；lambda 块体规则原样（块尾无分号 = 值出口，块内任意语句）；块体分支间无分隔符（`}` 闭合），单行体分支间 `;`；空块体合法（值为空值，值位慎用）。

### E. 结构约束

分支 ≥ 1（`? { }` / `? x { }` 编译错）；求值自上而下短路；无 fallthrough；型内禁混（同一 match 块所有分支同型）。

## §7.2 `? :` 中缀三元 ⏳ 待定

- 纯表达式形态 `c ? a : b`；
- 块形态 `c ? {A;} : {B;}` 与单支省略 `c ? {A;};` 曾提出，**块形态被评价为"不够 Cosat 化"，整体待定**；
- 若将来定案：优先级介于 `==`(2) 与 `>>`(1) 之间，右结合（见 [03-运算符](./03-运算符-OPERATORS.md)）；在此之前二元判断用 match 单守卫 + `_` 表达；
- 备选方向（未展开）：数据流风格的条件前缀形态。
