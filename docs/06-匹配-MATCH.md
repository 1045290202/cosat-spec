## 文法（EBNF）

```ebnf
match-expr   = "?" , [ scrutinee ] , branch-block ;       (* 无 scrutinee = cond 型 *)
scrutinee    = operand-banned ;                           (* 扫描到 { 止；内禁 -> >> ; , : *)
branch-block = "{" , branch , { branch } , "}" ;
branch       = branch-left , ":" , receiver ;
branch-left  = "_" | guard-operand | literal ;
guard-operand = operand ;                                 (* switch 型须含 _；cond 型禁 _；扫描到 : 止 *)
receiver     = operand | block ;                          (* 接收者，按接收点位计数 *)
```

## §7.1 match

**形态**：`?` 前缀 + 分支列表块；分支 = `分支左侧 : 接收者`：

```cosat
? {                                  # cond 型：条件分发（无数据随行，体须 0 接收点位）
    x < 0   : "负" -> @log;
    y > 10  : "正" -> @log;
    _       : C
}

? x {                                # switch 型：对单一被匹配值分发（值流入体）
    1      : "精确命中" -> @log;
    _ > 99 : "大数: " + _
    _      : "其他" -> @log;
}
```

**核心语义（接收点位匹配）**：分支体 = 接收者，但不必是函数——任何表达式按接收点位数参与匹配，编译期校验与数据量相等（公理 6 泛化）。点位收集与校验机制和链段（[04 §5.1](./04-链模型-CHAIN.md)）完全一致，差别仅在数据来源：

| 分支体 | 接收点位 | 行为 |
| --- | --- | --- |
| 字面量 / 变量引用 / 不含 `_`、`@fn` 的表达式 | 0 | 独立求值，结果 = 分支值（switch 型可按名引用被匹配值，如 `"大数: " + x`） |
| `@fn`（fn 取 N 参） | N | 数据按形参顺序流入并调用 |
| `@@fn` | N | 同 `@fn`——点位不跨层，外层只追加零参调用 |
| 含 `_` 的表达式（`_ + 1`） | 1 | `_` 绑定数据，表达式求值 |
| lambda 字面量 `\ x => …` | 形参数量 | 体位自动应用（❓ 开放问题 3） |
| 嵌套 `? _ { … }` / `~ _ { … }` | 1（arg 位 / 源位） | 数据流入内层结构，免 lambda 包装 |
| 嵌套 cond 型 `? { … }` / 定源循环 | 0 | 同字面量 |

```cosat
# 点位校验
? x { 1 : @twoArgFn }                # ✕ 2 点位 ≠ 1 值，编译错
? x { _ > 0 : @process }             # ✓ @process 取 1 参，消耗被匹配值

# 分支体嵌套 match（外层匹配值流入内层 arg 位）
? x {
    _ > 0 : ? _ {
        1     : "exact one"
        _ > 99: "huge"
        _     : "positive"
    }
    _     : "non-positive"
}
```

### 规则

- `branch → 分支左侧 ":" receiver`；
- 判定：`?` 位于**值位开头**（语句首、`>>` 后、`->` 后、`,` 后）即前缀 match，后必须紧跟 `{`（cond 型）或表达式 + `{`（switch 型）；`?` 前一 token 是操作数则为中缀（§7.2）；
- **守卫扫描到 `:` 为止**：守卫内禁 `:` `->` `>>` `;`（及未来 `? :` 三元）——守卫自定界；
- **守卫求值**：自上而下、第一为真即命中（短路）；switch 型被匹配值**求值一次**；
- **体形态与语义分号**：语句位单行体以 `;` 分隔（值丢弃，纯效果分发）；**值位分支体必须有值**——块体 lambda 以 `}` 为值出口，泛化表达式体本身即值；块体分支间无分隔符（`}` 闭合）；值位单行表达式体间同样无分隔符，体延伸至下一分支判定起点或 `}` 为止；
- **分支值 = 体应用于数据**（switch）/ **体调用或求值**（cond：0 位）；
- **零参形态** `\ => 表达式`：分支不需要被匹配值时不造形参；
- **应用与选择正交（由引用/调用区分接管）**：体写 `@pass` = 应用；写 `pass`（裸引用，0 位）= 选择（分支值 = 函数本身，未应用）：

```cosat
data -> ? _ { _ > 0 : @pass  _ : @fail };         # 应用型路由：命中支路以被匹配值调用对应函数
? x { _ > 0 : pass  _ : fail } >> def handler;    # 选择型路由：分支值 = 函数本身，值位存储备用
```

- **函数引用复用**：`_ > 0 : @incr`——分支路由到已有函数（策略 / 路由表）；
- **use-based 穷尽**：值位 match 必须含单独 `_` default 且各分支有值出口（编译错）；语句位可省 `_`（全假即跳过）；
- 无 fallthrough；型内禁混；分支 ≥ 1；
- **生成策略**：字面 `\ …` β-内联展开；泛化体直接嵌入（`_` 替换为被匹配值名）；守卫顺序映射条件链，`_` 对应最终分支；值位以隔离作用域包裹取值。分发形态与性能论证见 [design/06](../design/06-匹配.md)。

lambda 仍不可替代的场景（闭包捕获 / 多语句体 / 显式命名）见 [design/06](../design/06-匹配.md)。

## §7.1.1 switch 型：分支左侧与 `_` 角色

被匹配值表达式扫描到 `{` 为止（内禁 `->` `>>` `;` `,` `:`），**求值一次**存为被匹配值。分支左侧三种形态 = 被匹配值的三种用法：

| 分支左侧 | 语义 |
| --- | --- |
| 字面量（number / string / bool） | 严格相等比较（`_` 不出场） |
| 含 `_` 的守卫表达式 | `_` 绑定为被匹配值，求值为真即命中；**必须引用 `_`**，否则属 cond 型（型内禁混，编译错） |
| 单独 `_` | default，恒命中 |

- **裸标识符分支禁止**：比较还是绑定在无类型系统下真歧义，v1 编译错；
- **`_` 角色（全语言出场位）**：**位置型**（合并段点位 / match arg 位 / 循环源位：数据落点，恰一次）+ **引用型**（switch 守卫表达式内：次数不限、遮蔽外层、不可重绑定；泛化体内亦为引用型，如体 `_ + 1`、循环体 `_ * 2`）；lambda 体内部不使用 `_`；
- **绑定层级与遮蔽**：体 / 守卫中的 `_` 绑定当前层级的数据，内层遮蔽外层：

```cosat
~ xs {                           # 外层元素 = _（循环绑定）
    ? _ {                        # _ 遮蔽外层，绑定被匹配值
        _ > 0 : ~ _ {            # _ 遮蔽 match，绑定循环源
            @log                 # 此处 _ = 内层循环元素
        }
    }
}
```

- **双型定位**：cond 型管多条件任意表达式，switch 型管单值分发；模式匹配远期挂 switch 型（形态不变）⏳。

## §7.1.2 全变体清单

### A. 位置变体

| 位置 | 写法 | 约束 |
| --- | --- | --- |
| 语句位 | `? { … };` / `? x { … };` | 单行体分支间 `;`（值丢弃）；`_` 可省（全假跳过） |
| `>>` 右侧（值位） | `? x { _ > 0 : _  _ : 0 } >> def r;` | 必须含单独 `_` default + 各分支有值出口 |
| 链值位 / 参数组成员 | `? { … } -> @f;`、`? { … }, x -> @g;` | 同上，必须穷尽 |
| match 段（链内） | `data -> ? _ { 分支 } -> @next;` | 上游 = 被匹配值，分支值可继续流（切分判定同 [04](./04-链模型-CHAIN.md)） |
| 路由（应用） | `data -> ? _ { _ > 0 : @pass  _ : @fail };` | 命中支路以被匹配值调用对应函数（match 段，点位 1 = 1） |
| 路由（选择不应用） | `? x { _ > 0 : pass  _ : fail } >> def handler;` | 分支值 = pass/fail 本身（0 位引用），选出的函数经值位存储；括号包裹 match 不是合法站点形态（[05 §6.4](./05-函数-FUNCTIONS.md) 站点闭集无此形态） |
| 嵌套 | 守卫内 / 被匹配值（须括号） | 自然递归 |

### B. 被匹配值形态（switch 型）与括号规则

| 形态 | 写法 | 括号 |
| --- | --- | --- |
| 标识符 / dot 链 | `? x { … }`、`? obj.f { … }` | 不需要 |
| 裸表达式 | `? x + 1 { … }` | 不需要（扫描到 `{` 为止） |
| `@` 表达式 | `? @f { … }` | 不需要 |
| 含 match / lambda / 循环的嵌套前缀结构 | `? (? x { … }) { … }` | **必须加括号** |

被匹配表达式内**禁止** `>>` `->` `;` `,` `:`（语句级、分支级与参数组符号；`,` 禁令与循环源禁集对称，见 [07 §7.3.2](./07-循环-LOOP.md)）。

### C. 守卫 / 分支左侧规则（分型）

| 写法 | cond 型 `? { … }` | switch 型 `? x { … }` |
| --- | --- | --- |
| 布尔表达式（任意变量） | ✓ 核心形态 | ✕（必须含 `_`，否则属 cond 型） |
| 字面量 | ✕（truthy 恒真，逼用 switch 型） | ✓（严格相等比较） |
| 含 `_` 的表达式 | ✕（cond 型无被匹配值，`_` 未定义） | ✓（必须引用） |
| 单独 `_` | ✓ default | ✓ default |
| 裸标识符 | ✕（比较/绑定歧义） | ✕（同左） |

### D. 分支体（泛化）

体 = 接收点位匹配的表达式（§7.1 点位表）；lambda 块体规则原样（块尾无分号 = 值出口）；块体分支间无分隔符；语句位单行体分支间 `;`（值丢弃）；值位单行表达式体间无分隔符，各体自含至下一分支判定起点或 `}` 为止（同 §7.1）；空块体合法（值为空值，值位慎用）。

### E. 结构约束

分支 ≥ 1（`? { }` 编译错）；求值自上而下短路；无 fallthrough；型内禁混。

## §7.2 `? :` 中缀三元 ⏳ 待定

- 纯表达式形态 `c ? a : b`；块形态曾被评价"不够 Cosat 化"，整体待定；
- 若定案：优先级介于 `==`(2) 与 `>>`(1) 之间，右结合（[03-运算符](./03-运算符-OPERATORS.md)）；在此之前二元判断用 match 单守卫 + `_` 表达；
- 备选方向（未展开）：数据流风格的条件前缀形态。
