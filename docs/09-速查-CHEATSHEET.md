## §9 判定规则速查表

### 链与调用

| 写法 | 判定 | 语义 |
| --- | --- | --- |
| `data -> @f` | ✓ | `f(data)` |
| `a, b -> @f` | ✓ | `f(a, b)` |
| `data -> f` | ✕ | 站点位缺少 `@`（显式调用） |
| `@f;` | ✓ | `f()` |
| `@f -> @g` | ✓ | `g(f())` 源头值位 |
| `@@f;` | ✓ | `f()()` 右结合，内层先执行 |
| `data -> @h, _ -> @g` | ✓ | `g(h(), data)` @ 在参数组 |
| `data, fn -> @g` | ✓ | `g(data, fn)` 裸标识符传引用 |
| `data, @fn -> @g` | ✓ | `g(data, fn())` @ 调用入组 |
| `data -> @f -> 1, _, 2 -> @h` | ✓ | `h(1, f(data), 2)` |
| `data -> @(\ x => x * 2)` | ✓ | 内联立即调用（动态站点） |
| `data1, data2 -> @\ a, b => b, a -> @fn` | ✓ | 参数重排 → `fn(data2, data1)`；体到 `->` 止 |
| `\ x => x * 2 >> def double` | ✓ | 定义 = 构造 + 存储；单行体扫描到 `>>` 止 |
| `data -> @fn1, data2 -> @fn2` | ❓ | 按点位模型推导为 `fn2(fn1(data), data2)`，语义待定案（见 [04-链模型 §5.1](./04-链模型-CHAIN.md)） |
| `@1` / `@!f` | ✕ | 操作数不可调用 |
| `1 >> def x >> y;` | ❓ | 链式 `def` 语义待定（报错 or 连续赋值） |

### 站点位

| 写法 | 判定 | 语义 |
| --- | --- | --- |
| `data -> @obj.method` | ✓ | dot 链显式调用 |
| `data -> (@@fn)` | ✓（❓ 语义待对齐） | 动态站点，见 [05-函数 §6.4](./05-函数-FUNCTIONS.md) |
| `data -> { … }` | ✕ | 站点位禁块 |
| `a, b -> { … }` | ✕ | lambda/调用不可区分，用 `\` |
| `data -> @` | ✕ | 站点位禁裸 `@` |

### match

| 写法 | 判定 | 语义 |
| --- | --- | --- |
| `? { c : \ => { A; }; _ : \ => { B; }; };` | ✓ | cond 型 match 语句位（单行体 `;` 分隔） |
| `? x { 1 : "A" _ > 99 : _ _ : "C" } >> def r;` | ✓ | switch 型值位：泛化体（常量 / `_` 直通 / default），穷尽 |
| `? x { _ > 0 : x + 1 _ : 0 } >> def r;` | ✓ | 0 位体按名引用被匹配值 |
| `? x { _ > 0 : @incr };` | ✓ | 函数引用路由，显式调用 |
| `? x { y : \ => { A; } }` | ✕ | 裸标识符分支：比较还是绑定真歧义 |
| `? x { y > 0 : \ => { A; } }` | ✕ | 守卫不含 `_` 属 cond 型，型内禁混 |
| `? x { _ > 0 : @twoArgFn }` | ✕ | 点位不匹配（2 位 ≠ 1 值） |
| `? { _ > 0 : \ => { A; } }` | ✕ | cond 型无被匹配值，`_` 未定义 |
| `? { … } >> def r;` | ✕ | 值位必须穷尽（无单独 `_` default）；守卫式 `_ > 99` 不构成穷尽保障 |
| `? ? x { A } { B }` | ✕ | 嵌套未加括号：内层 `{` 被外层吞并；须写 `? (? x { A }) { B }` |
| `? x + 1 { … }` | ✓ | switch 型裸表达式不加括号（扫描到 `{`） |
| `? x < 0` | ✕ | match 必须跟 `{` |

### 循环

| 写法 | 判定 | 语义 |
| --- | --- | --- |
| `~ xs { _ * 2 } >> def d;` | ✓ | 泛化表达式体恒收集 |
| `~ xs { \ x => x * 2 } >> def d;` | ✓ | lambda 表达式体恒有值（§7.3） |
| `~ xs { @log };` | ✓ | 引用体副作用遍历，语句位不收集 |
| `~ xs { \ x => { x -> @log; } };` | ✓ | 块体尾分号 → 不收集 |
| `~ xs { _ > 0 : @log };` | ✓ | 遍历带守卫：仅命中元素流入体 |
| `data -> ~ _ { \ x => x * 2 } -> @sum;` | ✓ | 站点位循环：源位 `_` = 上游，元素流入体形参 |
| `~ { i < 10 : \ => { … } }` | ✓ | 条件型 = while（多守卫 = 状态机） |
| `~ xs { x * 2 }` | ✕ | x 未绑定，元素未被消费 → `_ * 2` 或 lambda |
| `~ xs { @twoArgFn }` | ✕ | 点位不匹配 |
| `~ i < 10 { … }` | ✕ | 源是比较式，用条件型 |
| `~ 5 { … }` | ✕ | 数字字面量非源 |
| `~ { _ : \ => { A; } }` | ✕ | `_` 守卫 = 无限循环（v1 禁，随 break 解禁） |
| `data -> ~ xs { }` | ✕ | 站点位循环源必须 `_`，上游断流 |
| `~ _ * _ { }` | ✕ | 源层 `_` 仅单独作源；`_ * _` 另犯两处引用（[07-循环 §7.3.2](./07-循环-LOOP.md) 白名单） |
| `data -> ? _ { … } -> ~ _ { \ x => … }` | ✓ | match 选出可迭代值、站点循环接续——复杂源需求的链式分解形态（两段各自绑定） |
| `(~ xs { \ x => { x -> @log; } }) >> def r;` | ✕ | 值位循环体必须有值出口 |
| `data -> ~ { 守卫 }` | ✕ | 条件型不可入链 |
