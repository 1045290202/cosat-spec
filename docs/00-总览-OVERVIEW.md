## 语言定位

Cosat 是一门**数据流范式**的语言：代码即数据从左向右的流动，语法的一切设计服务于"看清数据去了哪里"。

语言名 Cosat 由 **Co**urier 与 St**at**ion 组合而来，直接对应"数据投递"这一核心思想；脚本文件扩展名为 `.cst`。

## §1 设计公理

1. **数据流高于一切**：一切语法以数据流向为基础，数据从左向右流动；
2. **目的地殿后**：值在前，目的地（变量 / 消费函数）在后——`值 >> 变量`、`实参 -> 函数`、`值 >> def 名字`；
3. **符号单一含义**：每个符号只有一个语义、一个方向，不兼职：`->` 专职数据流，`=>` 专职函数定义，`@` 专职调用（见 [02-符号](./02-符号-SYMBOLS.md)）；
4. **角色不明则前缀声明**：凡角色无法从左侧推断的（形参、取值、占位），用前缀标记声明（`\`、`@`、`_`）；
5. **歧义必须在文法层消灭**：当两种语义角色在词法上不可区分时，用结构（不同符号）区分，不依赖位置或语境；两写法仅差单字符且语义不同时，弱者非法（防 typo 静默漂移）；
6. **接收点显式**：链路中 `->` 右侧是**接收者**，`->` 的作用 = 暴露接收者的**接收点**与上游实参对应。接收者必须自带**显式**的接收点——每个接收者恰一个落点声明：函数类 = 形参表（裸标识符 / dot 链的形参在定义处声明，lambda / 动态站点在括号内声明），match / 循环 = 裸 `_`（arg 位 / 源位）；**不含落点的裸算式、裸 `@`、块不能作接收者**，含 `_` 落点的泛化表达式按接收点位模型计位（见下）；每跳点位总数 = 上游数据量（编译期校验）。链外（链首 / 语句位 / 值位）构造自带头部操作数（可为表达式），不承担接收职责，不受此限。**接收 ≠ 使用**：裸露约束的是**接收动作**的落点（arg 位 / 源位 / 形参表 / 合并段落点）；数据落定后在接收者内部参与表达式（守卫 `_ > 99`、循环体 `_ * 2`、函数体 `x + 1`）属于**使用**，不受此限——恰如形参裸列于定义处，而函数体内 `x + 1` 自由。分界线：接收点之后（`{` 内、形参表后）即使用域；若禁使用，守卫与收集语义皆不可能。
   > **接收点位模型**：公理 6 泛化为**接收点位匹配**——接收者不必是函数，任何表达式按**接收点位数**参与匹配（字面量 / 变量 = 0 位，`_` = 1 位，`@fn` = fn 形参数量），点位数与数据量编译期校验；"体必须是函数"是该模型的特例。详见 [06-匹配](./06-匹配-MATCH.md) 与 [04-链模型 §5.1](./04-链模型-CHAIN.md)。

## 核心符号速览

| 符号 | 唯一含义 | 示例 |
| --- | --- | --- |
| `>>` | 存储：值 → 名字 | `1 >> def x` |
| `->` | 数据流：左侧 → 右侧接收者（仅链段使用） | `data -> @f` |
| `=>` | 函数构造：形参 → 体 | `\ x => x * 2` |
| `\` | 构造前缀：开启函数定义 | `\ x => x * 2` |
| `@` | 调用：标记调用点（唯一调用标记） | `@f`、`data -> @f` |
| `_` | 占位：数据落点 / default 守卫 / 守卫内引用 | `-> @f, _ -> @g` |
| `?` | 分支：match 多路分发 | `? x { 1 : "one" }` |
| `~` | 循环：遍历 / 遍历带守卫 / 条件 / 站点位 | `~ xs { _ * 2 }`、`data -> ~ _ { … }` |
| `:` | 分支分隔：分支左侧与体之间 | `_ > 0 : @incr` |
| `;` | 语义分号：数据未到终点，值在此丢弃 | `x -> @log;` |
| `def` | 定义目的地标记 | `>> def x` |

完整分工与保留约束见 [02-符号](./02-符号-SYMBOLS.md)。

## 快速示例

```cosat
# 定义 = 构造 + 存储；分支体泛化：常量分支免 lambda 包装
\ n => ? n {
    0 : 0
    1 : 1
    _ : (n - 1 -> @fib) + (n - 2 -> @fib)
} >> def fib;

10 -> @fib -> @print;                # → 55

# 管道 + 参数重排（@\ 惯用形）+ 多返回值
data1, data2 -> @\ a, b => b, a -> @fn;   # → fn(data2, data1)

# 循环：表达式体收集（map）、遍历带守卫（filter）
~ nums { _ * 2 } >> def doubled;
~ nums { _ > 0 : @print }                # 仅正数元素流入 @print
```
